# Kenji Auto Rentals 🚗💨

A modern, responsive full-stack car rental platform designed to handle hour-precise scheduling, prevent vehicle scheduling collisions, manage user authentication, and log custom delivery options securely.

🌐 **[Live Deployment Link](https://github.io)**

---

## 🛠️ Tech Stack & Architecture

- **Frontend Interface:** React 19, Vite, CSS3 (Advanced Flexbox & Grid layouts)
- **Backend-as-a-Service:** Supabase (Authentication & PostgreSQL Database Engine)
- **Database Logic:** PostgreSQL with `btree_gist` extensions for structural constraint rules
- **Deployment Pipeline:** GitHub Pages hosted via automated build integrations

---

## 🚀 Key Features Built From Scratch

### 🕒 Hour-Precise 12-Hour Scheduling
Replaced native calendar input configurations with an intuitive selection layout. Users pick calendar dates paired with independent dropdown menus displaying localized 12-hour AM/PM hour choices, while the background engine seamlessly transforms inputs into precise 24-hour ISO string formats (`YYYY-MM-DDTHH:00:00`).

### 🔒 Zero-Collision Double-Booking Prevention
Implemented a multi-layered verification barrier. Before submission, the frontend runs a conditional logic validation scan to check for overlaps. If bypassed, a backend PostgreSQL database-level exclusion constraint (`tstzrange` GiST index) acts as a structural guardrail to reject intersecting timestamps instantly.

### 👥 Relational Profile Matching & Authentication
Configured a secure user lifecycle sequence. When creating an account, user data is routed safely through Supabase Auth, storing metadata records that join automatically with a public `profiles` table to populate user names throughout the site dashboard seamlessly.

### 📍 Conditional Vehicle Delivery System
Designed a dynamic workflow toggle option. Users can request direct-to-door delivery inside the scheduling modal. Checking the request dynamically mounts required location address validation input rows while recording data cleanly to the active database.

### 🧹 Secure State Memory Cleanup & Mobile Fluidity
Engineered an active state wipe routine. Logging out completely resets components, flushes client history lists out of browser caching memory, and redirects views back home. Mobile layouts use a fluid mobile navigation hamburger overlay that automatically collapses upon selecting an option.

## 💻 Local Environment Installation Guide

Follow these steps to run the full-stack architecture locally on your machine:

1. **Clone the Repository:**
   ```bash
   git clone https://github.com
   cd "Final Dev Kenji"
   ```

2. **Install Code Dependencies:**
   ```bash
   npm install
   ```

3. **Configure Your Environment Secrets:**
   Create a hidden configuration file named `.env.local` in the root folder path and add your public Supabase API credentials:
   ```env
   VITE_SUPABASE_URL=https://supabase.co
   VITE_SUPABASE_ANON_KEY=your-actual-long-anon-key-string
   ```

4. **Launch the Local Development Server:**
   ```bash
   npm run dev
   ```
   Open your browser to `http://localhost:5173` to test the environment interactively.

## 🛡️ Database Schema Configurations Reference

For structural tracking compatibility, the PostgreSQL table configurations require the following database columns and constraints:

```sql
-- Create Profiles Table Linkage
CREATE TABLE public.profiles (
  id UUID REFERENCES auth.users ON DELETE CASCADE PRIMARY KEY,
  full_name TEXT
);

-- Create Main Reservations Log
CREATE TABLE public.reservations (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  user_id UUID REFERENCES public.profiles(id) ON DELETE CASCADE,
  client_name TEXT,
  car_name TEXT NOT NULL,
  start_time TIMESTAMPTZ NOT NULL,
  end_time TIMESTAMPTZ NOT NULL,
  wants_delivery BOOLEAN DEFAULT FALSE,
  delivery_location TEXT
);

-- Enable Scheduling Guard Extension
CREATE EXTENSION IF NOT EXISTS btree_gist;

-- Enforce Multi-Tenant Double Booking Exclusion Constraint
ALTER TABLE public.reservations
ADD CONSTRAINT unique_reservation_car_time_slot EXCLUDE USING gist (
  car_name WITH =,
  tstzrange(start_time, end_time, '[]') WITH &&
);
